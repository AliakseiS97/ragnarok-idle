# CLAUDE.md — инструкция проекта для Claude Code

## Что это за проект
Idle/AFK кликер «Рагнарёк: Восхождение» на скандинавской мифологии. Бэкенд на Java + Spring Boot, позже — браузерный фронт поверх API. Проект служит двум целям: (1) портфолио для трудоустройства Java-backend разработчиком, (2) коммерческий продукт.

## ГЛАВНОЕ: где документация (читай перед любой задачей)
- **`docs/MASTER_GDD.md`** — полный дизайн игры + техспека: все системы, формулы, модель данных, API-контракт, дорожная карта. Это источник истины по механикам.
- **`docs/economy_constants.md`** — все числовые константы в виде markdown-таблиц (кривые HP/золота, цены героев, дропрейты, артефакты и т.д.). Бери числа отсюда.
- **`docs/economy.xlsx`** — тот же баланс в Excel (бинарный, читается хуже — используй economy_constants.md как текстовую версию).

**Всегда сверяйся с этими файлами. Не выдумывай формулы и числа — они уже заданы в доках.**

## Технологический стек (из GDD, часть XII)
- Java 17+, Spring Boot 3
- Spring Security (JWT), Spring Data JPA
- PostgreSQL + Flyway (миграции)
- springdoc-openapi (Swagger UI)
- JUnit 5 + Testcontainers для тестов
- Maven

## Критическое требование: big-number
HP/золото/DPS/множители на уровнях 5000+ превышают предел `double` (10^308). НИКОГДА не считай игровые величины в `long`/`double` напрямую. Используй класс `BigNum` (мантисса double + exponent long) с операциями ×, ÷, +, сравнением, log10. Все игровые формулы — через него. См. GDD §12.2.

## Стиль работы (важно для меня как автора)
- Я учусь на Java-backend — **объясняй ключевые решения кратко**, не пиши стены текста.
- Двигайся **по спринтам из дорожной карты GDD (часть XIII)**, один за раз. Не пытайся написать всю игру сразу.
- Каждый логический кусок — как отдельный коммит/PR (я так привык на Mate Academy).
- Сервер — единственный источник истины (античит, GDD §12.7): клиент шлёт действия, не значения.
- Все траты/крафт/перерождение — транзакционны (`@Transactional`).

## Порядок разработки (дорожная карта)
- **Спринт 0 (СЕЙЧАС):** каркас Spring Boot + Postgres + Flyway + JWT + Swagger + класс `BigNum` с тестами.
- **Спринт 1:** MVP-кликер — Player, Avatar, золото, AFK-доход, кликер (10 подуровней + таймер-босс), 15 стартовых героев, покупка/апгрейд за золото, перерождение + Пепел.
- **Спринт 2:** множители вех, артефакты, баферы, шахты + кристаллы, щит-боссы.
- **Спринт 3:** редкость, дневной босс, дуэли, костёр, скрытые герои, гача.
- **Спринт 4:** боги (пантеон за Слёзы Фрейи), VIP, кланы, мировые боссы, торговля.
- **Спринт 5:** PvP-меха как «лицо», FTUE, монетизация, аналитика.

## Что НЕ делать
- Не рисовать/не генерировать арт и модели героев — их автор проекта делает сам.
- Не использовать браузерные storage API (localStorage) во фронт-прототипах — состояние держать на бэкенде или в памяти.
- Не менять числа баланса в коде «на глаз» — источник в economy_constants.md.
- **Никогда не добавлять AI-атрибутику в git** — ни в сообщения коммитов, ни в описания PR. Никаких `Co-Authored-By: Claude`, `Claude-Session:`, «🤖 Generated with Claude Code» и подобных строк/трейлеров. Единственный автор — пользователь.
