# Рагнарёк: Восхождение — бэкенд

Idle/AFK кликер на скандинавской мифологии. Spring Boot + PostgreSQL.
Полный дизайн и формулы — в `docs/MASTER_GDD.md`, числа — в `docs/economy_constants.md`.

## Запуск (Спринт 0)
Нужен JDK 17+ и Maven.

```bash
mvn spring-boot:run
```

По умолчанию поднимается на H2 в памяти (без установки Postgres):
- Swagger UI: http://localhost:8080/swagger-ui.html
- H2 консоль: http://localhost:8080/h2-console (JDBC URL: `jdbc:h2:mem:ragnarok`)

## Тесты
```bash
mvn test
```
Ключевой тест — `BigNumTest`: проверяет игровую математику на числах, которые
переполнили бы обычный double (уровни 5000+).

## Balance Simulator
Консольная утилита, которая «играет» в игру по **реальным формулам проекта** (класс
`CombatEngine`, `EconomyCurves`, `Saga`, цены/DPS героев и т.д. — чистая математика, без
Spring и БД) и печатает таймлайн прогресса, стены и итоговый отчёт. Нужна для проверки
баланса: где игрок упирается в стены, сколько времени до этажа/босса/перерождения,
насколько Слава ускоряет повторное прохождение.

Запуск (параметры опциональны, показаны значения по умолчанию):
```bash
mvn -q compile exec:java \
  -Dexec.mainClass=com.ragnarok.idle.simulator.BalanceSimulator \
  -Dexec.args="clicksPerSecond=5 wallThresholdSeconds=600 maxSimulatedHours=24 rebirths=3"
```
Помимо консоли пишет полный журнал событий в `target/simulation-report.csv`
(колонки `game_time_seconds,event,floor,gold,dps,ash`).

Целевой баланс (проверяется симулятором): 100 этажей проходятся примерно за
**~55 мин при 3 кликах/сек** (обычный игрок) и **~40 мин при 8 кликах/сек**
(безостановочный тапер).

Пример вывода (итоговый отчёт, параметры по умолчанию, 5 кликов/сек):
```
======================================================================
ИТОГОВЫЙ ОТЧЁТ СИМУЛЯЦИИ
======================================================================
Параметры: клики/сек=5, порог стены=600с, лимит=24ч, ребёртов до стопа=3
Достигнуто: этаж 3921, ребёртов 2, Слава 2.64K, симулировано 23:59:58 игрового времени

-- Время до ключевых рубежей --
  этаж 10   : 00:02:42
  этаж 100  : 00:50:58
  ребёрт #1 : 09:36:30
  ребёрт #2 : 19:03:10

-- Разбивка времени --
  активный прогресс : ~99% (стены появляются только при слабом кликере/после ребёрта)
```
При оптимальной жадной стратегии стен почти нет — скорость гейтится темпом убийств
(хиты/сек) и притоком золота. Чтобы увидеть стены, уменьшите `clicksPerSecond`.

## Что готово (Спринт 0)
- Каркас Spring Boot, Maven, профиль H2/Postgres.
- **Класс `BigNum`** (мантисса+экспонента) — сердце игровой математики, с тестами.
- Flyway-миграция V1 (таблица player).
- Swagger подключён.
