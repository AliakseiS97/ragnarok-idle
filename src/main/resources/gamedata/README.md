# Ragnarok: Ascension — Mythology Game Data

Игровые данные, сконвертированные из [norse-heathenry-pagan-api-dataset](https://github.com/ksherbondy/norse-heathenry-pagan-api-dataset) (лицензия **CC0-1.0** — свободно для коммерческого использования).

## Куда класть в проекте `ragnarok-idle`

Структура папки повторяет структуру Spring Boot проекта — просто скопируй содержимое `src/` поверх своего `src/`:

```
ragnarok-idle/
└── src/main/resources/
    ├── gamedata/                              # JSON-сиды (справочные данные)
    │   ├── heroes_gods_seed.json              # 34 бога: роли, редкость, умения, арт-промпты
    │   ├── runes_seed.json                    # 40 рун: тиры 1-4, эффекты, флейвор
    │   ├── artifacts_seed.json                # 6 легендарных артефактов + сет-бонусы
    │   ├── events_seed.json                   # 5 сезонных ивентов
    │   └── art_prompt_templates.json          # ИДЕЯ: шаблоны AI-генерации карточек
    ├── lore/                                  # Полные тексты для энциклопедии/саг
    │   ├── voluspa.json                       # Вёлуспа (сюжет Рагнарёка)
    │   ├── havamal_api_v1_gold.json           # 164 строфы = подсказки на загрузку
    │   └── gylfaginning.json                  # Основной лор богов
    └── db/changelog/changes/
        ├── 20-create-mythology-tables.sql     # 4 таблицы
        └── 21-seed-mythology-data.sql         # Все INSERT'ы
```

## Подключение миграций

В `db.changelog-master.yaml` добавь после существующих changeset'ов:

```yaml
  - include:
      file: db/changelog/changes/20-create-mythology-tables.sql
  - include:
      file: db/changelog/changes/21-seed-mythology-data.sql
```

> Номера `20-`/`21-` — переименуй под свою нумерацию, если в проекте уже есть файлы с такими префиксами.

## Таблицы

| Таблица | Записей | Что хранит |
|---|---|---|
| `deity_heroes` | 34 | Боги как герои: `hero_key`, роль, редкость, умение, руна-якорь, `art_prompt` |
| `runes` | 40 | Старший футарк (24, тиры 1-3 по аттам) + младший (16, тир 4), `effect_type` + `effect_value` |
| `artifacts` | 6 | Легендарки с `owner_hero_key` → сет-бонус x2 в команде с владельцем |
| `seasonal_events` | 5 | Ивенты с месяцем и механикой |

## Механики, заложенные в данные

- **Руна-якорь**: у каждого бога поле `rune_anchor`. Экипировка «своей» руны = x2 эффект умения. JOIN: `deity_heroes.rune_anchor LIKE '%' || runes.name || '%'` (или добавь FK при желании).
- **Сет артефакт+владелец**: `artifacts.owner_hero_key = deity_heroes.hero_key`.
- **Тиры рун по аттам**: исторически старший футарк делится на 3 атта по 8 рун — использовано как тиры 1/2/3, младший футарк целиком тир 4 (древние/редкие).
- **Ивенты по реальному календарю**: Йоль в январе, Сигрблот в апреле и т.д. — стимул сезонного ретеншена.

## ИДЕЯ: AI-генерация контента (отмечено)

Каждый герой и артефакт уже содержит готовый `art_prompt` (собран из символов, цветов и животных бога из первоисточников). Шаблоны для остального — иконки рун, флейвор-тексты, подсказки на загрузку из Хавамаля — в `gamedata/art_prompt_templates.json`. Пайплайн: сид из БД → шаблон → генератор изображений/LLM → ассеты для фронта.
